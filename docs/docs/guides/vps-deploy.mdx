# Deploy Vectora on a VPS

This guide takes you from a blank Ubuntu server to a running Vectora instance accessible via HTTPS — in under 15 minutes.

The same steps apply to any Debian-based Linux (Ubuntu 22.04+, Debian 12+).

:::info Prerequisites
- A VPS with at least **2 vCPU / 4 GB RAM / 20 GB SSD**
- A domain or subdomain pointing to the server's IP (e.g. `ai.yourcompany.com`)
- Your **Vectora license token** from [vectora.company/dashboard](https://vectora.company/dashboard)
- An API key for your chosen LLM provider (Google AI Studio, OpenAI, or Anthropic)
:::

## 1. Recommended VPS providers

| Provider | Suitable plan | Approx. cost |
|---|---|---|
| Hetzner Cloud | CX22 (2 vCPU / 4 GB) | €4–6/mo |
| DigitalOcean | Droplet 2 vCPU / 4 GB | $24/mo |
| AWS Lightsail | 2 vCPU / 4 GB | $20/mo |
| Vultr | 2 vCPU / 4 GB | $24/mo |

For teams larger than 5, use 4 vCPU / 8 GB.

## 2. Install Docker

SSH into your server and run:

```bash
# Install Docker (official script, works on Ubuntu/Debian)
curl -fsSL https://get.docker.com | sh

# Allow your user to run Docker without sudo
sudo usermod -aG docker $USER && newgrp docker

# Verify
docker --version
docker compose version
```

## 3. Open firewall ports

```bash
sudo ufw allow 22/tcp    # SSH — keep this open first
sudo ufw allow 80/tcp    # HTTP (redirected to HTTPS by Nginx)
sudo ufw allow 443/tcp   # HTTPS
sudo ufw enable
sudo ufw status
```

## 4. Create the project directory

```bash
mkdir -p ~/vectora && cd ~/vectora
```

## 5. Create docker-compose.yml

```yaml title="~/vectora/docker-compose.yml"
services:
  vectora:
    image: ghcr.io/vectora-company/vectora:latest
    restart: unless-stopped
    ports:
      - "127.0.0.1:8080:8080"   # only accessible from localhost (Nginx proxies it)
    volumes:
      - vectora_data:/app/data
      - vectora_lancedb:/app/lancedb
    env_file: .env
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 20s

volumes:
  vectora_data:
  vectora_lancedb:
```

## 6. Create the .env file

```bash
cat > .env << 'EOF'
# ── Required ─────────────────────────────────────────────
VECTORA_TOKEN=your_token_here          # from vectora.company/dashboard

# ── LLM provider (pick one) ──────────────────────────────
LLM_PROVIDER=google-genai
GOOGLE_API_KEY=AIza...                 # Google AI Studio
# LLM_PROVIDER=openai
# OPENAI_API_KEY=sk-...
# LLM_PROVIDER=anthropic
# ANTHROPIC_API_KEY=sk-ant-...

# ── RAG (required for document indexing) ─────────────────
COHERE_API_KEY=your_cohere_key         # free tier available at cohere.com

# ── Optional ─────────────────────────────────────────────
TAVILY_API_KEY=                        # for web search (leave blank to disable)
ENABLE_WEB_SEARCH=false
LOG_LEVEL=INFO
EOF
```

Edit `.env` and fill in your real values:

```bash
nano .env
```

## 7. Start Vectora

```bash
docker compose up -d

# Follow startup logs
docker compose logs -f vectora
```

Wait until you see:

```
vectora  | ✓ Server listening on http://0.0.0.0:8080
```

## 8. Install Nginx and get an SSL certificate

```bash
sudo apt update && sudo apt install -y nginx certbot python3-certbot-nginx
```

Create the Nginx site config (replace `ai.yourcompany.com` with your domain):

```bash
sudo nano /etc/nginx/sites-available/vectora
```

Paste:

```nginx title="/etc/nginx/sites-available/vectora"
server {
    listen 80;
    server_name ai.yourcompany.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name ai.yourcompany.com;

    ssl_certificate     /etc/letsencrypt/live/ai.yourcompany.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/ai.yourcompany.com/privkey.pem;
    include             /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam         /etc/letsencrypt/ssl-dhparams.pem;

    client_max_body_size 100M;

    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    add_header Referrer-Policy strict-origin-when-cross-origin;

    location / {
        proxy_pass         http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection "upgrade";
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_buffering    off;   # required for SSE streaming
        proxy_cache        off;
        proxy_read_timeout 600s;
    }
}
```

Enable the site and obtain the certificate:

```bash
sudo ln -s /etc/nginx/sites-available/vectora /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# Get Let's Encrypt certificate (free)
sudo certbot --nginx -d ai.yourcompany.com
```

Certbot installs an auto-renewal cron job automatically. You can verify it:

```bash
sudo systemctl status certbot.timer
```

## 9. Verify

Open `https://ai.yourcompany.com` in your browser. You should see the Vectora login screen.

- The **first account** that signs up automatically becomes an admin.
- Invite team members via **Settings → Members**.

```bash
# Quick health check from the command line
curl https://ai.yourcompany.com/health
# → {"status":"ok","version":"..."}
```

## 10. Connect via the REST API

Once Vectora is running, you can connect external applications to it using the REST API. See the [API Integration guide](./api-integration) for complete examples.

Quick test:

```bash
# Create an API key in: Settings → API Keys → New key
export API_KEY="vk_live_..."
export BASE_URL="https://ai.yourcompany.com"

curl -s "$BASE_URL/v1/health" \
  -H "Authorization: Bearer $API_KEY" | jq
```

## Maintenance

### Update to the latest version

```bash
cd ~/vectora
docker compose pull
docker compose up -d
```

Vectora applies database migrations automatically on startup.

### View logs

```bash
docker compose logs -f vectora
docker compose logs --since 1h vectora
```

### Restart

```bash
docker compose restart vectora
```

### Backup

```bash
#!/bin/bash
# Save as ~/vectora/backup.sh and add to cron: 0 3 * * * bash ~/vectora/backup.sh
set -e
cd ~/vectora
DATE=$(date +%Y%m%d)

docker run --rm \
  -v vectora_data:/data -v $(pwd)/backups:/backup \
  alpine tar czf /backup/data-$DATE.tar.gz /data

docker run --rm \
  -v vectora_lancedb:/data -v $(pwd)/backups:/backup \
  alpine tar czf /backup/lancedb-$DATE.tar.gz /data

echo "Backup done: backups/data-$DATE.tar.gz + lancedb-$DATE.tar.gz"
```

```bash
mkdir -p ~/vectora/backups
chmod +x ~/vectora/backup.sh

# Add to crontab (daily at 3 AM)
(crontab -l 2>/dev/null; echo "0 3 * * * bash ~/vectora/backup.sh") | crontab -
```
