# IDE Integration

Vectora integrates with VS Code and JetBrains IDEs, letting you chat with the agent directly from your editor.

## VS Code Extension

### Install

Search for **"Vectora"** in the VS Code Marketplace, or install via the CLI:

```bash
code --install-extension vectora.vectora-vscode
```

### Configure

1. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
2. Run **Vectora: Connect**.
3. Enter your Vectora URL and API key.

```json
// .vscode/settings.json (team-shared config)
{
  "vectora.baseUrl": "https://your-vectora-domain.com",
  "vectora.projectId": "proj_abc123"
}
```

### Usage

| Command | Action |
|---|---|
| `Ctrl+Shift+V` | Open Vectora chat panel |
| Select code → right-click → **Ask Vectora** | Send selection with context |
| `Ctrl+Shift+E` | Explain selected code |
| `Ctrl+Shift+R` | Refactor selected code |

The extension automatically includes the open file and selected lines as context.

### Inline completions

Enable Vectora as an inline completion provider:

```json
{
  "vectora.inlineCompletions.enabled": true,
  "vectora.inlineCompletions.triggerCharacter": "~"
}
```

Type `~` at the end of a line to trigger an inline suggestion from the agent.

## JetBrains Plugin

Compatible with IntelliJ IDEA, PyCharm, WebStorm, GoLand, and all JetBrains IDEs.

### Install

1. Go to **Settings → Plugins → Marketplace**.
2. Search for **"Vectora"** and click **Install**.
3. Restart the IDE.

### Configure

**Settings → Tools → Vectora**:
- **Server URL**: `https://your-vectora-domain.com`
- **API Key**: `vk_live_...`
- **Default project**: select from dropdown (populated after connection)

### Usage

- **Alt+Shift+V** (Win/Linux) / **Option+Shift+V** (Mac): Open Vectora tool window.
- Right-click on any code → **Vectora → Explain / Refactor / Generate tests**.
- The tool window has a persistent chat history per project.

## Zed (ACP server)

Vectora supports the [Agent Communication Protocol (ACP)](https://agentcommunicationprotocol.dev), making it usable as a sub-agent in Zed's agent mode.

```json
// Zed settings.json
{
  "agent": {
    "profiles": {
      "default": {
        "tools": {
          "vectora": {
            "acp_url": "https://your-vectora-domain.com/acp"
          }
        }
      }
    }
  }
}
```

## Context sent to Vectora

The IDE integrations send:
- Selected text or cursor position context
- Open file content (truncated to fit the context window)
- File path and language

No workspace files are sent unless you explicitly paste them or use the **Index workspace** feature.
