# RAG Pipeline

Vectora uses **Retrieval-Augmented Generation (RAG)** to let the AI answer questions about your documents with high precision.

## Pipeline overview

```
Document upload
     │
     ▼
┌─────────────┐
│   Chunking   │  Split into 800-token chunks with 100-token overlap
└─────────────┘
     │
     ▼
┌─────────────┐
│ Cohere Embed │  Dense vectors (embed-v4.0, 1024 dims)
└─────────────┘
     │
     ▼
┌─────────────┐
│   LanceDB    │  Stored locally (hybrid: dense + BM25)
└─────────────┘

At query time:
     │
     ▼
┌─────────────┐
│Query expand  │  LLM generates 3 alternative phrasings
└─────────────┘
     │
     ▼
┌─────────────┐
│Hybrid search │  Dense similarity + BM25 keyword, RRF fusion
└─────────────┘
     │
     ▼
┌─────────────┐
│   Reranker   │  Cohere rerank-v3.5 — top 8 from 30 candidates
└─────────────┘
     │
     ▼
┌─────────────┐
│  LLM answer  │  Final response with citations
└─────────────┘
```

## Supported file types

| Type | Extensions |
|---|---|
| Documents | `.pdf`, `.docx`, `.doc`, `.odt` |
| Text | `.txt`, `.md`, `.rst` |
| Spreadsheets | `.csv`, `.xlsx`, `.xls` |
| Code | `.py`, `.ts`, `.js`, `.go`, `.rs`, `.java`, `.c`, `.cpp`, and more |
| Data | `.json`, `.yaml`, `.toml`, `.xml` |

## Configuring chunking

In **Settings → RAG** or via `vectora.toml`:

```toml
[rag]
chunk_size = 800        # tokens per chunk
chunk_overlap = 100     # overlap between consecutive chunks
top_k = 8               # chunks to pass to LLM
rerank = true           # enable Cohere reranking
rerank_top_n = 3        # final chunks after reranking
query_expansion = true  # generate alternative query phrasings
```

## Cohere API key

RAG requires a Cohere API key for embeddings and reranking. The **free tier** is sufficient for most teams (10k embed calls/month, 1k rerank calls/month).

```bash
# .env
COHERE_API_KEY=your_cohere_api_key
```

Sign up at [cohere.com](https://cohere.com) — no credit card required for the free tier.

## Tips for better retrieval

1. **Keep documents focused** — split large PDFs into topic-specific files when possible
2. **Use descriptive filenames** — `q3-2025-financial-report.pdf` not `report.pdf`
3. **Add metadata tags** — use tags like `["legal", "2025"]` to filter at query time
4. **Enable query expansion** — Vectora rephrases queries to catch paraphrases
5. **Increase `top_k` for complex questions** — longer documents may need `top_k=15`
