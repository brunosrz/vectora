# Quick Start

Get from zero to your first AI conversation in under 5 minutes.

## Prerequisites

- Vectora is running (see [Installation](/getting-started/installation))
- You have your `VECTORA_TOKEN` from the dashboard

## 1. Create the root account

Open `http://localhost:8080` in your browser. On first run, Vectora prompts you to create the **root (admin) account**:

```
Name:     your name
Email:    admin@yourcompany.com
Password: (choose a strong password)
```

The root account has full administrative access to the workspace.

## 2. Create your first project

Projects are isolated workspaces — each has its own knowledge base, conversation history, and settings.

1. Click **New project** in the sidebar
2. Name it (e.g., "Engineering", "Legal", "Research")
3. Optionally set a **system prompt** to define the agent's persona

## 3. Send your first message

Type any question in the chat input. Vectora will respond using the configured LLM provider.

```
You: Summarize what Vectora is.
Vectora: Vectora is a self-hosted AI agent that...
```

## 4. Add documents to the knowledge base (RAG)

To chat about your own documents:

1. Click **Knowledge base** in the project sidebar
2. Drag and drop files (PDF, DOCX, TXT, MD, code files, etc.)
3. Wait for indexing to complete (shown as a progress bar)
4. Start asking questions about the documents

:::tip
Vectora uses **hybrid search** (semantic + keyword) with Cohere reranking for high-precision retrieval. Asking "summarize the contract clause about termination" will find the right passage even in a 500-page PDF.
:::

## 5. Invite your team

1. Go to **Settings → Team**
2. Click **Invite user**
3. Enter their email and role (Admin, Editor, Viewer)
4. They receive an invitation email to create their account

## Using the REST API

Every project exposes a REST API for programmatic access. Create an API key in **Settings → API Keys**, then:

```bash
curl -X POST https://your-vectora.com/v1/chat \
  -H "Authorization: Bearer vct_key_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": "proj_xxx",
    "message": "What are the main risks in the attached contract?"
  }'
```

→ [Full API reference](/api-reference/overview)

## Using with Claude Desktop (MCP)

Vectora ships an MCP server. Add it to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "vectora": {
      "command": "npx",
      "args": ["-y", "@vectora/mcp"],
      "env": {
        "VECTORA_URL": "http://localhost:8080",
        "VECTORA_API_KEY": "vct_key_xxx"
      }
    }
  }
}
```

→ [MCP integration guide](/guides/mcp-integration)
