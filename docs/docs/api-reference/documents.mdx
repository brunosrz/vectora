# Documents API

## Upload a document

```http
POST /v1/documents
Content-Type: multipart/form-data
```

Supported formats: `.pdf`, `.docx`, `.txt`, `.md`, `.csv`, `.xlsx`, `.py`, `.ts`, `.js`, and most code file types.

```bash
curl -X POST http://localhost:8080/v1/documents \
  -H "Authorization: Bearer vct_key_write_xxx" \
  -F "project_id=proj_01j..." \
  -F "file=@q3-report.pdf" \
  -F "metadata={\"tags\":[\"finance\",\"q3\"]}"
```

Response:
```json
{
  "data": {
    "id": "doc_01jxxxxxxxxxx",
    "project_id": "proj_01jxxxxxxxxxx",
    "filename": "q3-report.pdf",
    "size_bytes": 204800,
    "status": "indexing",
    "chunks": null,
    "metadata": { "tags": ["finance", "q3"] },
    "created_at": "2025-01-01T00:00:00Z"
  }
}
```

The `status` field transitions: `uploading` → `indexing` → `ready` (or `failed`).

## List documents

```http
GET /v1/documents?project_id={id}&status=ready&limit=20
```

## Get document status

```http
GET /v1/documents/{document_id}
```

## Delete a document

```http
DELETE /v1/documents/{document_id}
```

Deletes the document and removes all its chunks from the vector store.

## Search documents (semantic)

```http
POST /v1/search
```

```json
{
  "project_id": "proj_01jxxxxxxxxxx",
  "query": "termination clause penalties",
  "limit": 5,
  "filters": {
    "tags": ["legal"]
  }
}
```

Response:
```json
{
  "data": [
    {
      "document_id": "doc_xxx",
      "filename": "contract-2025.pdf",
      "chunk_id": "chunk_yyy",
      "score": 0.94,
      "excerpt": "In the event of early termination, the party shall pay...",
      "page": 12
    }
  ]
}
```
