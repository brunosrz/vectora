# Monitoring

Vectora exposes Prometheus metrics, structured JSON logs, and a `/health` endpoint.

## Health endpoint

```
GET /health
```

Returns `200 OK` when the server is ready to handle requests.

```json
{
  "status": "ok",
  "version": "1.2.0",
  "db": "connected",
  "storage": "connected"
}
```

## Prometheus metrics

Vectora exposes metrics at `/metrics` (requires `VECTORA_METRICS_TOKEN` to be set):

```
GET /metrics
Authorization: Bearer <VECTORA_METRICS_TOKEN>
```

Key metrics:

| Metric | Type | Description |
|---|---|---|
| `vectora_requests_total` | Counter | HTTP requests by endpoint and status |
| `vectora_request_duration_seconds` | Histogram | Request latency |
| `vectora_active_sessions` | Gauge | Currently active user sessions |
| `vectora_rag_query_duration_seconds` | Histogram | RAG pipeline latency |
| `vectora_license_checks_total` | Counter | License validations by result |
| `vectora_agent_tasks_total` | Counter | Agent tasks by status |
| `vectora_documents_indexed_total` | Counter | Documents successfully indexed |

## Grafana dashboard

Import the official dashboard (ID: `vectora-overview`) from grafana.com, or download from [vectora.company/monitoring/grafana.json](https://vectora.company/monitoring/grafana.json).

### Prometheus scrape config

```yaml
# prometheus.yml
scrape_configs:
  - job_name: vectora
    bearer_token: "<VECTORA_METRICS_TOKEN>"
    static_configs:
      - targets: ["vectora:8000"]
    metrics_path: /metrics
```

## Log format

Logs are emitted to stdout as structured JSON:

```json
{
  "timestamp": "2025-03-15T14:23:00.123Z",
  "level": "info",
  "event": "chat.request",
  "user_id": "usr_abc",
  "project_id": "proj_xyz",
  "duration_ms": 1240,
  "model": "claude-3-5-haiku-20251001",
  "tokens": 480
}
```

### Centralized logging

**Loki + Grafana** (recommended for self-hosted):

```yaml
# docker-compose.yml addition
logging:
  driver: loki
  options:
    loki-url: "http://loki:3100/loki/api/v1/push"
    loki-labels: "service=vectora"
```

**AWS CloudWatch**:

```yaml
logging:
  driver: awslogs
  options:
    awslogs-group: "/vectora/app"
    awslogs-region: "us-east-1"
```

## Uptime monitoring

Use [BetterStack Uptime](https://betterstack.com/uptime) or [Upptime](https://upptime.js.org) to monitor the `/health` endpoint and set up incident notifications.

Recommended check intervals:
- `/health` → every 60 seconds
- License validation endpoint → every 5 minutes

## Alerts

Example Prometheus alerting rules:

```yaml
# alerts.yml
groups:
  - name: vectora
    rules:
      - alert: VectoraDown
        expr: up{job="vectora"} == 0
        for: 2m
        annotations:
          summary: "Vectora is down"

      - alert: HighLatency
        expr: histogram_quantile(0.95, vectora_request_duration_seconds_bucket) > 2
        for: 5m
        annotations:
          summary: "p95 latency > 2s for 5 minutes"

      - alert: LicenseExpired
        expr: increase(vectora_license_checks_total{result="expired"}[5m]) > 0
        annotations:
          summary: "License check returned expired"
```
