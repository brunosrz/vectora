# Storage Backends

See [Reference → Storage Backends](/reference/storage-backends) for a full reference on all storage options.

## Quick setup

For a new installation, the fastest path is:

### Local (single node)

No additional config needed. Add a persistent volume to docker-compose.yml:

```yaml
volumes:
  uploads:

services:
  vectora:
    volumes:
      - uploads:/data/uploads
```

### Cloudflare R2 (recommended for production)

Zero egress costs — ideal if your server is outside AWS.

1. Create an R2 bucket in the Cloudflare dashboard.
2. Create an R2 API token with **Object Read & Write** permission.
3. Add to `.env`:

```env
STORAGE_BACKEND=s3
S3_ENDPOINT_URL=https://<account-id>.r2.cloudflarestorage.com
S3_BUCKET=vectora-documents
S3_REGION=auto
S3_ACCESS_KEY_ID=<r2-key-id>
S3_SECRET_ACCESS_KEY=<r2-secret>
```

### AWS S3

```env
STORAGE_BACKEND=s3
S3_BUCKET=my-vectora
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=AKIA...
S3_SECRET_ACCESS_KEY=...
```

See [Reference → Storage Backends](/reference/storage-backends) for IAM policy, GCS, MinIO, and migration instructions.
