# Docker Deployment

## Full docker-compose.yml

```yaml title="docker-compose.yml"
services:
  vectora:
    image: ghcr.io/vectora-company/vectora:latest
    restart: unless-stopped
    ports:
      - "8080:8080"
      - "9090:9090"
    volumes:
      - vectora_data:/app/data
      - vectora_lancedb:/app/lancedb
      - ./vectora.toml:/app/vectora.toml:ro  # optional config override
    environment:
      VECTORA_TOKEN: "${VECTORA_TOKEN}"

      # LLM — pick one provider
      LLM_PROVIDER: "${LLM_PROVIDER:-google-genai}"
      GOOGLE_API_KEY: "${GOOGLE_API_KEY:-}"
      OPENAI_API_KEY: "${OPENAI_API_KEY:-}"
      ANTHROPIC_API_KEY: "${ANTHROPIC_API_KEY:-}"
      OLLAMA_URL: "${OLLAMA_URL:-}"

      # Required for RAG
      COHERE_API_KEY: "${COHERE_API_KEY}"

      # Optional
      TAVILY_API_KEY: "${TAVILY_API_KEY:-}"   # for web search
      LOG_LEVEL: "${LOG_LEVEL:-INFO}"
      ENABLE_WEB_SEARCH: "${ENABLE_WEB_SEARCH:-false}"
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 15s

volumes:
  vectora_data:
  vectora_lancedb:
```

## Environment variables reference

| Variable | Required | Description |
|---|---|---|
| `VECTORA_TOKEN` | ✓ | Your license token from the dashboard |
| `LLM_PROVIDER` | ✓ | `google-genai`, `openai`, `anthropic`, `ollama` |
| `GOOGLE_API_KEY` | if google-genai | Google AI Studio API key |
| `OPENAI_API_KEY` | if openai | OpenAI API key |
| `ANTHROPIC_API_KEY` | if anthropic | Anthropic API key |
| `OLLAMA_URL` | if ollama | e.g. `http://ollama:11434` |
| `COHERE_API_KEY` | ✓ (for RAG) | Cohere API key for embeddings |
| `TAVILY_API_KEY` | optional | For web search in agents |
| `LOG_LEVEL` | optional | `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `ENABLE_WEB_SEARCH` | optional | `true` to allow web search (default: `false`) |

## Update to latest version

```bash
docker compose pull
docker compose up -d
```

Vectora applies database migrations automatically on startup.

## Backup

```bash
# Backup data volume
docker run --rm \
  -v vectora_data:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/vectora-data-$(date +%Y%m%d).tar.gz /data

# Backup LanceDB
docker run --rm \
  -v vectora_lancedb:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/vectora-lancedb-$(date +%Y%m%d).tar.gz /data
```

Add to cron for daily backups:
```bash
0 3 * * * cd /opt/vectora && bash backup.sh
```
