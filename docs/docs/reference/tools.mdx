# Built-in Tools

Vectora agents have access to a set of built-in tools that let them interact with the filesystem, terminal, web, and your knowledge bases. Tools are invoked automatically by the orchestrator based on the task.

## File & Filesystem

| Tool | Description |
|------|-------------|
| `read_file` | Read a file by path. Returns content as a string. |
| `write_file` | Write or overwrite a file. Creates parent directories as needed. |
| `edit_file` | Apply a targeted string replacement to a file (old_string → new_string). |
| `list_dir` | List files and directories under a given path. |
| `search_files` | Glob pattern search across the filesystem (e.g. `**/*.py`). |
| `grep` | Regex search across file contents with optional path filter. |
| `move_file` | Move or rename a file. |
| `delete_file` | Delete a file or empty directory. |

## Terminal

| Tool | Description |
|------|-------------|
| `run_command` | Execute a shell command. Returns stdout, stderr, and exit code. |
| `run_script` | Run an inline script in bash, Python, or Node. |

All terminal tools run in the project directory. Commands are sandboxed to the workspace unless the admin explicitly enables broader access.

## Web & Search

| Tool | Description |
|------|-------------|
| `web_search` | Perform a web search and return snippets + URLs. |
| `fetch_url` | Fetch the text content of a URL (HTML stripped). |
| `fetch_url_raw` | Fetch raw HTML or Markdown. Useful for scraping docs. |

## Git

| Tool | Description |
|------|-------------|
| `git_status` | Show working tree status. |
| `git_diff` | Show unstaged or staged diff. |
| `git_log` | Show recent commits. |
| `git_add` | Stage files. |
| `git_commit` | Create a commit with a message. |
| `git_checkout` | Switch or create branches. |

## RAG / Documents

| Tool | Description |
|------|-------------|
| `rag_search` | Hybrid semantic + BM25 search over your indexed documents. Returns ranked chunks with source metadata. |
| `rag_ingest` | Index a file or URL into the knowledge base. |
| `rag_list_sources` | List all indexed document sources. |
| `rag_delete_source` | Remove a source and its embeddings from the index. |

## MCP (Model Context Protocol)

Vectora supports MCP servers. When an MCP server is configured, its exposed tools appear alongside built-in tools with the prefix `mcp_<server-name>_<tool>`.

```bash
# Enable an MCP server in config.toml
[[mcp_servers]]
name = "filesystem"
command = "npx"
args = ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/projects"]
```

See [MCP Server](./mcp-server) for full configuration.

## Skills

Skills are user-defined tool collections loaded from YAML files. They allow teams to add domain-specific tools (e.g. internal API clients, custom scripts) without modifying core Vectora.

```yaml title="skills/jira.yml"
name: jira
description: "Create and query Jira issues"
tools:
  - name: create_issue
    command: "python skills/jira_client.py create --summary {summary} --type {type}"
  - name: search_issues
    command: "python skills/jira_client.py search --query {query}"
```

## Disabling Tools

Tools can be restricted per-workspace in `Settings → Agent Tools`:

```toml title="config.toml"
[agent_tools]
disabled = ["run_command", "delete_file", "fetch_url_raw"]
```

Disabling `run_command` prevents the agent from executing shell commands while leaving file and RAG tools active.
