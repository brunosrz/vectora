La API REST `/v1/` de Vectora cubre **4 endpoints reales** hoy: clasificación de texto, extracción estructurada y envío/seguimiento de jobs asíncronos. No confundas esto con una API completa de chat/documentos — eso todavía es roadmap, [detallado aquí](./roadmap).

¿Corres tu propia instancia self-hosted y quieres automatizar contra la misma API que usa el frontend (chat, RAG, gateways, settings)? Mira [Integración Self-Hosted](./self-hosted-integration) — es real y está documentada, solo que sin la misma garantía de estabilidad que `/v1/*`.
