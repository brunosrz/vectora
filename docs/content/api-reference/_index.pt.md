A API REST `/v1/` do Vectora hoje cobre **4 endpoints reais**: classificação de texto, extração estruturada, e submissão/acompanhamento de jobs assíncronos. Não confunda com uma API completa de chat/documentos — isso ainda é roadmap, [detalhado aqui](./roadmap).

Roda sua própria instância self-hosted e quer automatizar contra a mesma API que o frontend usa (chat, RAG, gateways, settings)? Veja [Integração Self-Hosted](./self-hosted-integration) — é real e documentada, só que sem a mesma garantia de estabilidade que `/v1/*`.
