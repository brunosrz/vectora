Vectora's `/v1/` REST API covers **4 real endpoints** today: text classification, structured extraction, and submitting/tracking async jobs. Don't confuse this with a full chat/documents API — that's still roadmap, [detailed here](./roadmap).

Running your own self-hosted instance and want to automate against the same API the frontend uses (chat, RAG, gateways, settings)? See [Self-Hosted Integration](./self-hosted-integration) — it's real and documented, just not the same stability guarantee as `/v1/*`.
