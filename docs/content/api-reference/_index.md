A API REST `/v1/` do Vectora hoje cobre **4 endpoints reais**: classificação de texto, extração estruturada, e submissão/acompanhamento de jobs assíncronos. Não confunda com uma API completa de chat/documentos — isso ainda é roadmap, [detalhado aqui](./roadmap).
