# Configuration Reference

Vectora is configured via a `.env` file in the same directory as your `docker-compose.yml`.

## Required variables

| Variable | Example | Description |
|---|---|---|
| `VECTORA_TOKEN` | `vk_...` | License token from your dashboard |
| `VECTORA_DOMAIN` | `chat.your-company.com` | Public domain used to generate URLs |
| `POSTGRES_PASSWORD` | `str0ng_passw0rd` | PostgreSQL password |

## LLM providers

At least one provider must be configured.

| Variable | Description |
|---|---|
| `ANTHROPIC_API_KEY` | Claude models (Haiku, Sonnet, Opus) |
| `OPENAI_API_KEY` | GPT-4o, GPT-4o-mini, o3 |
| `GOOGLE_API_KEY` | Gemini models |
| `GROQ_API_KEY` | Fast inference: Llama 3, Mixtral |
| `OLLAMA_BASE_URL` | Local models via Ollama (e.g., `http://localhost:11434`) |
| `OPENAI_COMPATIBLE_BASE_URL` | Any OpenAI-compatible endpoint |

## Embedding providers

| Variable | Description |
|---|---|
| `COHERE_API_KEY` | Recommended: `embed-multilingual-v3.0` |
| `OPENAI_API_KEY` | `text-embedding-3-small` / `text-embedding-3-large` |
| `OLLAMA_EMBED_MODEL` | Local embeddings (e.g., `nomic-embed-text`) |

## RAG configuration

| Variable | Default | Description |
|---|---|---|
| `RAG_CHUNK_SIZE` | `512` | Tokens per chunk |
| `RAG_CHUNK_OVERLAP` | `64` | Overlap between chunks |
| `RAG_TOP_K` | `8` | Documents retrieved per query |
| `RAG_RERANKER_TOP_N` | `4` | Documents passed to LLM after reranking |
| `RAG_SCORE_THRESHOLD` | `0.4` | Minimum similarity score |
| `RAG_HYBRID_WEIGHT` | `0.5` | Dense vs sparse weight (0 = pure BM25, 1 = pure dense) |

## Authentication

| Variable | Default | Description |
|---|---|---|
| `VECTORA_SESSION_SECRET` | — | **Required.** 32-byte hex secret for session signing |
| `VECTORA_INVITE_ONLY` | `false` | Require invite link to sign up |
| `VECTORA_MAX_USERS` | unlimited | Maximum registered users |
| `VECTORA_REQUIRE_EMAIL_VERIFY` | `true` | Require email verification on signup |

## Storage

| Variable | Default | Description |
|---|---|---|
| `STORAGE_BACKEND` | `local` | `local`, `s3`, `gcs`, `r2` |
| `STORAGE_LOCAL_PATH` | `/data/uploads` | Local storage directory |
| `S3_BUCKET` | — | S3 bucket name |
| `S3_REGION` | `us-east-1` | AWS region |
| `S3_ACCESS_KEY_ID` | — | AWS access key |
| `S3_SECRET_ACCESS_KEY` | — | AWS secret |
| `S3_ENDPOINT_URL` | — | For S3-compatible (MinIO, R2) |

## Email (optional)

| Variable | Default | Description |
|---|---|---|
| `SMTP_HOST` | — | SMTP server hostname |
| `SMTP_PORT` | `587` | SMTP port |
| `SMTP_USER` | — | SMTP username |
| `SMTP_PASSWORD` | — | SMTP password |
| `SMTP_FROM` | `noreply@{VECTORA_DOMAIN}` | From address |

## Performance

| Variable | Default | Description |
|---|---|---|
| `VECTORA_WORKERS` | `2` | Uvicorn worker processes |
| `VECTORA_RATE_LIMIT_RPM` | `60` | Requests per minute per user |
| `VECTORA_CONTEXT_WINDOW` | `128000` | Max context tokens for chat |

## Full example

```env
# Required
VECTORA_TOKEN=vk_live_abc123...
VECTORA_DOMAIN=chat.your-company.com
POSTGRES_PASSWORD=super_strong_password_here
VECTORA_SESSION_SECRET=64_hex_chars_here

# LLM
ANTHROPIC_API_KEY=sk-ant-...
COHERE_API_KEY=...

# Optional
VECTORA_INVITE_ONLY=true
STORAGE_BACKEND=s3
S3_BUCKET=my-vectora-uploads
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=AKIA...
S3_SECRET_ACCESS_KEY=...
```
