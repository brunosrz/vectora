# Storage Backends

Vectora stores uploaded files (documents, exports) in a configurable backend.

## Supported backends

| Backend | Best for |
|---|---|
| `local` | Single-node deploys, development |
| `s3` | AWS S3 or any S3-compatible service |
| `gcs` | Google Cloud Storage |
| `r2` | Cloudflare R2 (S3-compatible, egress-free) |
| `minio` | Self-hosted S3-compatible (via `s3` + endpoint URL) |

## Local (default)

Files stored at `STORAGE_LOCAL_PATH` (default: `/data/uploads` inside the container).

```env
STORAGE_BACKEND=local
STORAGE_LOCAL_PATH=/data/uploads
```

Ensure the path is mounted as a persistent volume:

```yaml
# docker-compose.yml
volumes:
  - ./uploads:/data/uploads
```

:::warning
Local storage does not replicate. Use object storage for multi-node or high-availability deployments.
:::

## AWS S3

```env
STORAGE_BACKEND=s3
S3_BUCKET=my-vectora-documents
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
S3_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
```

Minimum IAM policy:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
      "Resource": "arn:aws:s3:::my-vectora-documents/*"
    },
    {
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": "arn:aws:s3:::my-vectora-documents"
    }
  ]
}
```

## Cloudflare R2

R2 is S3-compatible with no egress fees — ideal for large document stores.

```env
STORAGE_BACKEND=s3
S3_ENDPOINT_URL=https://<account-id>.r2.cloudflarestorage.com
S3_BUCKET=vectora-documents
S3_REGION=auto
S3_ACCESS_KEY_ID=<r2-access-key-id>
S3_SECRET_ACCESS_KEY=<r2-secret-access-key>
```

## MinIO (self-hosted)

```env
STORAGE_BACKEND=s3
S3_ENDPOINT_URL=http://minio:9000
S3_BUCKET=vectora
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=minioadmin
S3_SECRET_ACCESS_KEY=minioadmin
```

Add MinIO to `docker-compose.yml`:

```yaml
services:
  minio:
    image: minio/minio
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin
    volumes:
      - minio_data:/data
    ports:
      - "9000:9000"
      - "9001:9001"
```

## Google Cloud Storage

```env
STORAGE_BACKEND=gcs
GCS_BUCKET=my-vectora-documents
GOOGLE_APPLICATION_CREDENTIALS=/secrets/gcp-sa-key.json
```

Mount the service account key as a secret volume.

## Migrating between backends

```bash
# Export from current backend
vectora storage export --output ./storage-backup/

# Switch backend in .env, restart

# Import into new backend
vectora storage import --input ./storage-backup/
```
