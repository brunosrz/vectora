# MCP Server

Vectora exposes an [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server, making it usable as a tool source for any MCP-compatible AI client (Claude Desktop, Zed, Cursor, custom agents).

## What is MCP?

MCP is an open protocol for AI applications to securely connect to tools and data sources. By running Vectora's MCP server, any MCP client can:

- Search your RAG knowledge base
- Index new documents
- Query Vectora projects
- Run agent tasks

## Connecting

### Claude Desktop

```json
// ~/Library/Application Support/Claude/claude_desktop_config.json (macOS)
// %APPDATA%\Claude\claude_desktop_config.json (Windows)
{
  "mcpServers": {
    "vectora": {
      "command": "npx",
      "args": ["-y", "@vectora/mcp-server"],
      "env": {
        "VECTORA_BASE_URL": "https://your-vectora-domain.com",
        "VECTORA_API_KEY": "vk_live_...",
        "VECTORA_PROJECT_ID": "proj_abc123"
      }
    }
  }
}
```

### Zed

```json
// ~/.config/zed/settings.json
{
  "context_servers": {
    "vectora": {
      "command": {
        "path": "npx",
        "args": ["-y", "@vectora/mcp-server"],
        "env": {
          "VECTORA_BASE_URL": "https://your-vectora-domain.com",
          "VECTORA_API_KEY": "vk_live_...",
          "VECTORA_PROJECT_ID": "proj_abc123"
        }
      }
    }
  }
}
```

### Any MCP client (SSE transport)

Vectora also exposes an HTTP SSE endpoint:

```
https://your-vectora-domain.com/mcp
Authorization: Bearer vk_live_...
```

## Available tools

| Tool | Description |
|---|---|
| `vectora_search` | Semantic search over indexed documents |
| `vectora_chat` | Send a message to the Vectora agent |
| `vectora_index_url` | Index a URL into the RAG knowledge base |
| `vectora_list_documents` | List indexed documents |

### `vectora_search`

```json
{
  "query": "how does the auth middleware work?",
  "project_id": "proj_abc123",
  "top_k": 5
}
```

Returns ranked chunks with source attribution.

### `vectora_chat`

```json
{
  "message": "Refactor the payment service to use async/await",
  "project_id": "proj_abc123"
}
```

Runs a full agent turn and returns the response.

## Authentication

The MCP server uses the same API keys as the REST API. Minimum required scope: `read` for search, `write` for indexing.

## Running the MCP server locally

```bash
npx @vectora/mcp-server
# or
pip install vectora
vectora mcp-server --stdio
```

The `--stdio` flag uses stdio transport (required for Claude Desktop / Zed).
