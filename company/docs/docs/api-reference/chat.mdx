# Chat API

## Send a message

```http
POST /v1/chat
```

Sends a message to the AI agent in a specific project and returns the response.

### Request

```json
{
  "project_id": "proj_01jxxxxxxxxxx",
  "message": "Summarize the Q3 financial report.",
  "conversation_id": "conv_01jxxxxxxxxxx",  // optional — omit to start a new conversation
  "stream": false,                           // optional — true for SSE streaming
  "options": {
    "rag": true,        // use the project's knowledge base (default: true)
    "web_search": false // enable real-time web search (default: false)
  }
}
```

### Response

```json
{
  "data": {
    "id": "msg_01jxxxxxxxxxx",
    "conversation_id": "conv_01jxxxxxxxxxx",
    "role": "assistant",
    "content": "The Q3 financial report shows...",
    "sources": [
      {
        "document_id": "doc_01jxxxxxxxxxx",
        "filename": "q3-report.pdf",
        "page": 3,
        "excerpt": "Total revenue for Q3 was $4.2M..."
      }
    ],
    "tokens": {
      "prompt": 512,
      "completion": 256,
      "total": 768
    },
    "created_at": "2025-01-01T00:00:00Z"
  }
}
```

### Streaming (SSE)

Set `"stream": true` to receive the response as a stream of Server-Sent Events:

```bash
curl -X POST http://localhost:8080/v1/chat \
  -H "Authorization: Bearer vct_key_xxx" \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{"project_id":"proj_xxx","message":"Hello","stream":true}'
```

Each SSE event:
```
data: {"delta":"Hello","type":"text"}
data: {"delta":" there","type":"text"}
data: {"type":"done","usage":{"prompt":10,"completion":5}}
```

## Retrieve conversation history

```http
GET /v1/chat/history?project_id={id}&conversation_id={id}&limit=50
```

```json
{
  "data": [
    {
      "id": "msg_xxx",
      "role": "user",
      "content": "What is Vectora?",
      "created_at": "2025-01-01T00:00:00Z"
    },
    {
      "id": "msg_yyy",
      "role": "assistant",
      "content": "Vectora is a self-hosted AI agent...",
      "sources": [...],
      "created_at": "2025-01-01T00:00:01Z"
    }
  ],
  "meta": { "has_more": false }
}
```

## List conversations

```http
GET /v1/conversations?project_id={id}&limit=20
```

## Delete a conversation

```http
DELETE /v1/conversations/{conversation_id}
```
