# Authentication

## API keys

Vectora uses API keys for REST API authentication. Manage them in **Dashboard → API Keys**.

### Creating a key

```bash
# Via the dashboard: Settings → API Keys → New key
# Or via the API (requires an existing admin key):

curl -X POST http://localhost:8080/v1/api-keys \
  -H "Authorization: Bearer vct_key_admin_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "name": "n8n integration", "scopes": ["read", "write"] }'
```

Response:
```json
{
  "data": {
    "id": "key_01jxxxxxxxxxx",
    "name": "n8n integration",
    "scopes": ["read", "write"],
    "secret": "vct_key_01jxxxxx...",
    "created_at": "2025-01-01T00:00:00Z"
  }
}
```

:::danger One-time secret
The `secret` field is returned **only once** at creation time. Store it immediately.
:::

### Key format

```
vct_key_{scope}_{random_bytes}
```

- `vct_key_read_xxx` — read-only key
- `vct_key_write_xxx` — read+write key
- `vct_key_admin_xxx` — admin key

### Using a key

```http
POST /v1/chat HTTP/1.1
Host: your-vectora-instance.com
Authorization: Bearer vct_key_write_xxxx...
Content-Type: application/json
```

### Revoking a key

```bash
curl -X DELETE http://localhost:8080/v1/api-keys/key_01jxxxxxxxxxx \
  -H "Authorization: Bearer vct_key_admin_xxx"
```
