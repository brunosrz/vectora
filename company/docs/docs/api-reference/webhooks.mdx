# Webhooks

Vectora can send HTTP POST requests to your endpoints when certain events occur.

## Events

| Event | When |
|---|---|
| `message.created` | A new AI response is created |
| `document.indexed` | A document finishes indexing |
| `document.failed` | A document fails to index |
| `project.created` | A new project is created |
| `user.invited` | A new user is invited |

## Register a webhook

```http
POST /v1/webhooks
```

```json
{
  "url": "https://your-app.com/hooks/vectora",
  "events": ["message.created", "document.indexed"],
  "secret": "your_webhook_secret"
}
```

## Payload format

```json
{
  "id": "evt_01jxxxxxxxxxx",
  "type": "message.created",
  "created_at": "2025-01-01T00:00:00Z",
  "data": {
    "message_id": "msg_xxx",
    "project_id": "proj_xxx",
    "conversation_id": "conv_xxx",
    "content": "The Q3 report shows...",
    "role": "assistant"
  }
}
```

## Verifying signatures

Vectora signs each request with an HMAC-SHA256 of the raw body using your webhook secret:

```python
import hmac, hashlib

def verify(payload: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(
        secret.encode(),
        payload,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature)

# In your handler:
sig = request.headers["X-Vectora-Signature"]
is_valid = verify(request.body, sig, "your_webhook_secret")
```

```typescript
import { createHmac, timingSafeEqual } from "crypto";

function verify(payload: Buffer, signature: string, secret: string): boolean {
  const expected = createHmac("sha256", secret).update(payload).digest("hex");
  return timingSafeEqual(Buffer.from(expected), Buffer.from(signature));
}
```
