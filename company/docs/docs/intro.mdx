## What is Vectora?

Vectora is a licensable, self-hosted AI agent that you deploy on your own server. It gives your team a private, secure workspace for:

- **Conversational AI** — chat with context about your codebase, documents, spreadsheets, and any file on your server
- **RAG (Retrieval-Augmented Generation)** — index any document; Vectora finds the right information with hybrid semantic + keyword search
- **Agentic workflows** — a multi-agent orchestrator that can write code, browse the web, manage files, and use MCP tools in parallel
- **Multi-user workspace** — invite your team, create projects with isolated knowledge bases, and control permissions per project

## Why self-hosted?

| | Vectora (self-hosted) | SaaS alternatives |
|---|---|---|
| **Data privacy** | Your server, never leaves it | Stored on vendor infrastructure |
| **Cost** | Fixed license price | Per-seat + usage costs |
| **Customization** | Full control over LLM, models, config | Limited to vendor options |
| **Compliance** | LGPD, GDPR, internal policies | Depends on vendor |
| **Offline** | Works without internet | Requires cloud connection |
