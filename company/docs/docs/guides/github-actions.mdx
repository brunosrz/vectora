# GitHub Actions

Automate Vectora tasks in your CI/CD pipeline using the official GitHub Action or the TypeScript SDK.

## Official action

```yaml
# .github/workflows/vectora-review.yml
name: Code Review with Vectora

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Vectora PR Review
        uses: vectora/review-action@v1
        with:
          vectora-url: ${{ secrets.VECTORA_BASE_URL }}
          vectora-api-key: ${{ secrets.VECTORA_API_KEY }}
          project-id: ${{ secrets.VECTORA_PROJECT_ID }}
          # Optional: post review as a PR comment
          github-token: ${{ secrets.GITHUB_TOKEN }}
```

The action diffs the PR, sends changed files to the Vectora Coder Agent, and posts a structured review as a PR comment.

## Custom workflows with the SDK

```yaml
# .github/workflows/doc-summary.yml
name: Document summary on push

on:
  push:
    paths: ["docs/**/*.md"]

jobs:
  summarize:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: "22"

      - name: Install SDK
        run: npm install @vectora/sdk

      - name: Summarize changed docs
        env:
          VECTORA_BASE_URL: ${{ secrets.VECTORA_BASE_URL }}
          VECTORA_API_KEY: ${{ secrets.VECTORA_API_KEY }}
        run: |
          node - << 'EOF'
          const { Vectora } = require("@vectora/sdk");
          const { execSync } = require("child_process");

          const client = new Vectora();
          const changed = execSync("git diff --name-only HEAD~1 HEAD -- docs/")
            .toString().trim().split("\n").filter(Boolean);

          for (const file of changed) {
            const content = require("fs").readFileSync(file, "utf8");
            const response = await client.chat.send({
              projectId: process.env.VECTORA_PROJECT_ID,
              message: `Summarize this document in 3 bullet points:\n\n${content}`,
            });
            console.log(file + ":\n" + response.content + "\n");
          }
          EOF

```

## Security: storing secrets

Store credentials as **GitHub Actions Secrets** (never in code):

```
Settings → Secrets and variables → Actions → New repository secret
```

| Secret name | Value |
|---|---|
| `VECTORA_BASE_URL` | `https://your-vectora-domain.com` |
| `VECTORA_API_KEY` | `vk_live_...` |
| `VECTORA_PROJECT_ID` | `proj_abc123` |

## Rate limits

GitHub Actions jobs often run in parallel. The Vectora REST API enforces per-key rate limits:

| Plan | Rate limit |
|---|---|
| Plus | 60 req/min |
| Pro | 600 req/min |

Use a dedicated API key for CI to avoid interfering with interactive use.
