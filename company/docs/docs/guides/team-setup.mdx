# Team Setup

## Inviting users

1. Go to **Settings → Team**
2. Click **Invite user**
3. Enter their email and select a role
4. The user receives an invitation email with a setup link

### Roles

| Role | Projects | Documents | Users | Settings |
|---|---|---|---|---|
| **Root** | Full | Full | Full | Full |
| **Admin** | Full | Full | Manage | Most |
| **Editor** | Assigned | Upload/delete | — | — |
| **Viewer** | Assigned (read) | Read only | — | — |

## Project-level access

Users can be assigned to specific projects with per-project roles:

```http
POST /v1/projects/{id}/members
{ "user_id": "usr_xxx", "role": "editor" }
```

An `editor` at the workspace level can be a `viewer` in a specific project.

## Audit log

All user actions are logged in the audit trail (Pro plan):

- User logins and logouts
- Document uploads and deletions
- Message requests (user, project, timestamp)
- Settings changes
- API key creation and revocation

Access via **Settings → Audit log** or the API:

```http
GET /v1/audit-log?limit=100&user_id=usr_xxx
```
