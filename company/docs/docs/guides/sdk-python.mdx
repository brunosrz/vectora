# Python SDK

The `vectora` Python package provides a type-safe client for the Vectora REST API.

## Installation

```bash
pip install vectora
```

Requires Python 3.11+.

## Authentication

```python
from vectora import Vectora

client = Vectora(
    base_url="https://your-vectora-domain.com",
    api_key="vk_live_...",  # from Dashboard → API Keys
)
```

Or set environment variables:

```bash
export VECTORA_BASE_URL=https://your-vectora-domain.com
export VECTORA_API_KEY=vk_live_...
```

```python
from vectora import Vectora
client = Vectora()  # reads env vars automatically
```

## Chat

```python
# Single message
response = client.chat.send(
    project_id="proj_abc123",
    message="Summarize the architecture document.",
)
print(response.content)

# Streaming
for chunk in client.chat.stream(
    project_id="proj_abc123",
    message="Explain how the RAG pipeline works.",
):
    print(chunk.delta, end="", flush=True)
```

## Documents

```python
# Upload a document
with open("architecture.pdf", "rb") as f:
    doc = client.documents.upload(
        project_id="proj_abc123",
        file=f,
        filename="architecture.pdf",
    )
print(f"Indexed: {doc.id}")

# List documents
docs = client.documents.list(project_id="proj_abc123")
for d in docs:
    print(d.filename, d.status)

# Delete a document
client.documents.delete(document_id=doc.id)
```

## Projects

```python
# List projects
projects = client.projects.list()

# Create a project
project = client.projects.create(name="My Project")

# Get a project
project = client.projects.get(project_id="proj_abc123")
```

## Async client

```python
import asyncio
from vectora import AsyncVectora

async def main():
    client = AsyncVectora()
    response = await client.chat.send(
        project_id="proj_abc123",
        message="Hello from async Python!",
    )
    print(response.content)

asyncio.run(main())
```

## Error handling

```python
from vectora import VectoraError, AuthenticationError, RateLimitError

try:
    response = client.chat.send(project_id="proj_abc123", message="Hello")
except AuthenticationError:
    print("Invalid API key")
except RateLimitError as e:
    print(f"Rate limited. Retry after {e.retry_after}s")
except VectoraError as e:
    print(f"API error: {e.status_code} {e.message}")
```
