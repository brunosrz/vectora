# MCP Integration

Vectora exposes an **MCP (Model Context Protocol) server** that lets any MCP-compatible client — Claude Desktop, VS Code, Cursor, and others — use Vectora as a context source and agent tool.

## What you can do via MCP

- **Search your knowledge base** from within Claude Desktop
- **Upload documents** and trigger indexing
- **Execute Vectora agents** (Coder Agent, Search Agent) from your IDE
- **Query conversation history**

## Claude Desktop

Add to `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json
{
  "mcpServers": {
    "vectora": {
      "command": "npx",
      "args": ["-y", "@vectora/mcp@latest"],
      "env": {
        "VECTORA_URL": "http://localhost:8080",
        "VECTORA_API_KEY": "vct_key_write_xxx",
        "VECTORA_PROJECT_ID": "proj_01jxxxxxxxxxx"
      }
    }
  }
}
```

Restart Claude Desktop. You should see **Vectora** in the MCP tools panel.

## VS Code (via Roo-Cline or Claude extension)

```json
{
  "roo-cline.mcpServers": {
    "vectora": {
      "command": "npx",
      "args": ["-y", "@vectora/mcp@latest"],
      "env": {
        "VECTORA_URL": "http://localhost:8080",
        "VECTORA_API_KEY": "vct_key_write_xxx",
        "VECTORA_PROJECT_ID": "proj_01jxxxxxxxxxx"
      }
    }
  }
}
```

## Available MCP tools

| Tool | Description |
|---|---|
| `vectora_search` | Semantic search over project documents |
| `vectora_chat` | Send a message to the Vectora agent |
| `vectora_upload` | Upload a file to the knowledge base |
| `vectora_list_docs` | List indexed documents |
| `vectora_get_context` | Retrieve relevant context for a given query |

## Direct HTTP MCP server

Vectora also exposes an HTTP/SSE MCP server at `:9090` for integrations that support HTTP transport:

```
http://localhost:9090/mcp
```

:::info MCP version
Vectora implements **MCP protocol version 2024-11-05**. Compatibility with newer versions is maintained as long as there are no breaking changes.
:::
